Medicare AI

Medicare AI is a AI-powered healthcare appointment management website designed to help patients explore medical departments, find doctors, book appointments, and general healthcare guidance through an AI chatbot.

# Features

User Authentication: Patient registration and login.
Admin Panel: Secure admin login and doctor management.
Appointment Booking: Book and view appointments.
Appointment Cancellation: Cancel booked appointments.
AI Healthcare Assistant: Get general healthcare information and department suggestions.
Responsive Interface: User-friendly design for different screen sizes.
